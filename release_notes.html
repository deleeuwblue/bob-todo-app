Release v1.1.0

Release Notes: Target Due Date Support

Summary: Resolves Issue #1 by enabling users to assign target completion dates to tasks upon creation and viewing them in the task list.

Highlights & Changes

  • Backend (FastAPI & SQLAlchemy): Added due_date column to the Todo model and updated request/response schemas.
  • Frontend UI (HTML/CSS): Integrated a date picker into the task addition form and styled due date badges on task items.
  • Client Logic (app.js): Updated payload submission to send target dates and dynamically render due date tags on tasks.

API Updates

  • POST /api/todos: Accepts optional due_date (YYYY-MM-DD format).
  • PATCH /api/todos/{id}: Supports updating due_date.
  • GET /api/todos: Returns due_date in task responses.
